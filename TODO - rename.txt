Новое имя: `os_script` - operation system script.


Старое название: `pyshellscript`

NOTE:
PyOps - занят _дважды_. (к сожалению).
другие хорошие имена тоже заняты.

в Python нет популярной библиотеки с конкретным именем `os-script`

**`os-sys`** — сторонний пакет в PyPI, который добавляет декоративные элементы (прогресс-бары, спиннеры в терминале) для консольных скриптов.
